Customer Service Dashboard

Overview

The Customer Service Dashboard is designed to provide key metrics and insights related to customer interactions and satisfaction.
The dashboard offers a comprehensive view of agent performance and customer engagement, helping organizations enhance their customer service quality.

Features
Agent Performance Metrics:

Average Customer Satisfaction per Agent: Displays each agent's average customer satisfaction score.
Number of Interactions per Agent: Shows the total number of customer interactions handled by each agent.
Contact Type Metrics:


Number of Interactions per Contact Type: Tracks the number of interactions across different contact types (e.g., phone, email, chat).
Average Customer Satisfaction per Contact Type: Reports the average customer satisfaction score for each contact type.
Time-Based Metrics:


Day-wise Customer Satisfaction: Displays customer satisfaction trends over time.
Day-wise Customer Interaction: Shows the number of customer interactions per day.
